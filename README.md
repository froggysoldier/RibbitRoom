RibbitRoom
A Repository for the RibbitRoom Project
Anleitung für lokalen Server:
1.	node.js installieren https://nodejs.org/
2. Installationspfad merken (Ort wo Node.js liegt)
3. Pc neu starten
4. Windowstaste + R
5. cmd eingeben
6. Mithilfe von (cd Ordnername) in den Projektordner navigieren
7.In der bash: npm install eingeben
8.In der bash: npm start eingeben
9.Oder wenn npm start nicht geht(npx serve)
10.Server running unter:
http://localhost:3000 oder http://127.0.0.1:5000
